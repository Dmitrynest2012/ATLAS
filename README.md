# ATLAS

**ATLAS** — корпоративный портал здоровья сотрудников. Репозиторий содержит начальную версию интерфейса **v0.1.0**: хэдер, адаптивный левый сайдбар, основную рабочую область и меню пользователя «Гость».

> **Важно:** это прототип интерфейса, без авторизации и обработки медицинских данных. Публичные репозиторий и GitHub Pages не предназначены для конфиденциальных сведений сотрудников.

## Быстрый запуск (Windows 11 / VS Code)

1. Установите [Git](https://git-scm.com/downloads/win) и [Node.js LTS](https://nodejs.org/).
2. Откройте терминал в VS Code и выполните:

   ```powershell
   git clone https://github.com/Dmitrynest2012/ATLAS.git
   cd ATLAS
   npm ci
   npm run dev
   ```

3. Перейдите в браузере на **http://127.0.0.1:5173**. Изменения HTML/CSS/JS автоматически обновляются в браузере.

Для сборки выполните `npm run check` и `npm run build`. Готовый статический сайт окажется в `dist/`. Команда `npm run preview` откроет сборку по адресу `http://127.0.0.1:4173`.

Начальная версия использует стандартный Node.js и **не требует сторонних npm-пакетов** — это осознанный выбор для небольшого безопасного каркаса. Для дальнейших сложных модулей зависимости можно добавлять с фиксацией `package-lock.json`.

## Автоматическое обновление рабочей папки

После клонирования в PowerShell, открытом в папке ATLAS, **один раз** выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-auto-sync.ps1
```

Windows будет каждые пять минут синхронизировать локальную чистую ветку `main` с GitHub без запущенного VS Code или `npm run dev`. Локальные незакоммиченные изменения не перезаписываются, слияние допускается только fast-forward. Подробнее: [docs/AUTO_UPDATE.md](docs/AUTO_UPDATE.md).

## Автоматическая публикация сайта

Workflow `.github/workflows/pages.yml` при обновлении `main` проверяет, собирает и публикует сайт через GitHub Pages. **Однократно** выберите в GitHub `Settings → Pages → Build and deployment → Source: GitHub Actions`. После этого новые изменения публикуются без ручного npm на вашем компьютере. Публичный URL после успешной публикации: `https://dmitrynest2012.github.io/ATLAS/`.

## Управление интерфейсом

- SVG-«бутерброд» в хэдере разворачивает и сворачивает сайдбар; на телефоне открывает выдвижную панель.
- Состояние ширины сохраняется локально в браузере.
- Кнопки навигации переключают страницы-заготовки без перезагрузки.
- В правом верхнем углу пользователь «Гость», заглавная буква «Г» и пустое всплывающее меню.

# История изменений ATLAS

## 0.1.0 — 2026-10-17

- Создан адаптивный сайт-каркас: хэдер, сайдбар и рабочая область.
- Добавлен SVG-переключатель сайдбара с плавной анимацией и сохранением состояния.
- Добавлен гостевой профиль: кружок с «Г», имя «Гость», стрелка вниз и пустое выпадающее окно.
- Добавлены интерактивные страницы-заготовки и мобильное боковое меню.
- Подготовлены npm-команды для разработки, тестов и статической сборки без внешних зависимостей.
- Настроена автоматическая сборка и публикация через GitHub Actions / Pages (после включения Pages в настройках репозитория).
- Добавлены Windows PowerShell-скрипты для безопасной периодической синхронизации GitHub и инструкции.
- Созданы правила проекта, архитектура, документация автообновления и политика безопасности.

# Безопасность ATLAS

**Статус: прототип UI.** Этот публичный репозиторий и сайт на GitHub Pages пока не обрабатывают сведения о здоровье реальных людей.

## Запрещено публиковать

- Медицинские и персональные данные сотрудников, обследования, диагнозы, назначения и записи о посещениях.
- Пароли, токены GitHub, API-ключи, доступы к БД, дампы, `.env` и ключи шифрования.
- Реальные имена сотрудников, фотографии и иные идентификаторы без необходимого основания и защиты.

## До появления личных кабинетов

Необходимо отдельно согласовать требования законодательства о персональных данных (включая GDPR, если применимо), провести моделирование угроз и реализовать закрытый backend, серверную авторизацию, разграничение ролей, аудит доступа, защищённое хранение и передачу информации, политику хранения и удаления.

`localStorage` сейчас используется **только** для флага свёрнутости бокового меню. Он не предназначен для токенов и медицинских сведений.

Локальный автообновлятор проверяет origin, чистое состояние Git и fast-forward. Он не включает постоянный удалённый доступ к ПК; действует только в рамках зарегистрированного задания Windows текущего пользователя. Обновления npm запускаются с `--ignore-scripts`.

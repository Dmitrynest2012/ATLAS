# Разработка ATLAS

## VS Code (Windows 11)

1. Установить Git for Windows и Node.js LTS, перезапустить VS Code (чтобы обновился PATH).
2. `Ctrl+Shift+P` → **Git: Clone** → вставить `https://github.com/Dmitrynest2012/ATLAS.git`, выбрать папку, нажать **Open**.
3. В VS Code открыть `Terminal → New Terminal`, выполнить `npm ci` и `npm run dev`.
4. Открыть `http://127.0.0.1:5173`. Для остановки dev-сервера нажать `Ctrl+C`.
5. Один раз установить автообновление командой из README. Оно не требует открытого терминала/npm и работает в Windows Task Scheduler.

## Ключевые файлы

- `index.html` — положение и семантика хедера, сайдбара, основной области.
- `src/styles.css` — внешний вид, ширина меню, анимации, адаптивность.
- `src/main.js` — переключение меню, навигация, гостевой виджет и управление доступностью.

## Как готовить обновления

1. Внести правки, сохраняя договорённости в `docs/PROJECT_RULES.md`.
2. Проверить мобильный и desktop-режимы; проверить пустое пользовательское меню и переключение боковой панели.
3. Выполнить `npm run check` и `npm run build`.
4. Обновить `CHANGELOG.md` и затронутую документацию.
5. Записать изменение в GitHub `main`; workflow публикует статическую версию, локальные рабочие копии обновятся безопасно.

Не редактируйте одну и ту же рабочую папку вручную во время удалённого обновления без сохранения изменений: Git видит только содержимое на диске, а не несохранённые вкладки VS Code. Скрипт пропускает обновление при найденных локальных изменениях.
